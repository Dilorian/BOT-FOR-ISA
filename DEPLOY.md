# Деплой бота на Railway

## 1. Локальный тест (перед деплоем)

```bash
pip install -r requirements.txt
cp .env.example .env
# открой .env и вставь реальные TOKEN и ID
python bot.py
```

Если в консоли появилось `Бот <имя> запущен!` — всё работает, можно деплоить.

## 2. Залить код на GitHub

```bash
git init
git add .
git commit -m "Discord score bot"
git branch -M main
git remote add origin https://github.com/<твой-юзернейм>/<репозиторий>.git
git push -u origin main
```

`.env` и `scores.db` не попадут в репозиторий — они в `.gitignore`.

## 3. Создать проект на Railway

1. Зайди на railway.app → New Project → Deploy from GitHub repo.
2. Выбери свой репозиторий с ботом.
3. Railway сам увидит `requirements.txt` и `Procfile` и определит,
   что нужно ставить зависимости и запускать `worker: python bot.py`.

## 4. Переменные окружения

В настройках проекта → Variables добавь:

| Переменная | Значение |
|---|---|
| `DISCORD_TOKEN` | токен бота из Discord Developer Portal |
| `GUILD_ID` | ID твоего сервера |
| `REPORT_CHANNEL_ID` | ID канала для заявок |
| `VERIFY_CHANNEL_ID` | ID канала верификации |
| `STAFF_ROLE_ID` | ID роли модераторов |
| `DB_PATH` | `/data/scores.db` (только если подключишь Volume, см. ниже) |

## 5. Важно: сохранение базы данных (SQLite)

Файловая система на Railway эфемерная — при каждом редеплое или
перезапуске контейнера файл `scores.db` будет создан заново пустым,
и все очки игроков потеряются.

Чтобы этого избежать:

1. В проекте на Railway: Settings → Volumes → Add Volume.
2. Примонтируй его, например, на `/data`.
3. Установи переменную `DB_PATH=/data/scores.db`.

Теперь база будет жить на постоянном диске и переживать редеплои.

## 6. Проверка после деплоя

Открой вкладку Deployments → Logs у сервиса на Railway.
Должна появиться строка `Бот <имя> запущен!` — значит бот онлайн
и виден в списке участников на Discord-сервере.

## Бесплатный лимит

Railway даёт около 500 часов исполнения в месяц бесплатно
(этого хватает примерно на один бот, работающий 24/7, ~720 часов
в месяц — так что месяц может не покрыться полностью).
Если лимит закончится — бот встанет на паузу до следующего месяца
или до пополнения баланса.
